🤖 AI Spam Message Detector

A simple Machine Learning project that detects whether a message is Spam or Not Spam.

🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- Tkinter
- Naive Bayes

📁 Project Files

- "app.py" — Graphical user interface
- "train.py" — Machine Learning model training
- "dataset.csv" — Training dataset

▶️ How to Run

Install the required libraries:

pip install pandas scikit-learn

Run the application:

python app.py

🎯 Features

- Spam message detection
- Not-spam detection
- Simple GUI
- Machine Learning based prediction
- Confidence score

📌 Project

This project was created for learning and understanding the basics of Machine Learning and Natural Language Processing.
